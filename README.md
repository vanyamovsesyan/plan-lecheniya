# План лечения

Конструктор плана лечения для стоматолога: зубная схема, этапы, скидки и PDF для пациента.

**Данные не покидают устройство.** Сервера у приложения нет, аккаунта нет, ничего никуда не отправляется. Планы лежат в хранилище браузера того телефона или компьютера, где их создали. Поэтому же: очистка данных сайта стирает планы — для переноса и страховки в приложении есть «💾 Резервная копия» (экспорт в файл и импорт на другом устройстве).

## Как пользоваться

Открыть ссылку в браузере. На телефоне — «Поделиться» → «На экран «Домой»» (iPhone) или «Установить приложение» (Android): дальше запускается как обычное приложение и **работает без интернета**.

## Что внутри

Один файл `index.html` — вся разметка, стили, код, шрифты и библиотеки PDF внутри него. Ни одной внешней загрузки: интернет нужен только чтобы страницу открыть в первый раз.

- `index.html` — приложение
- `sw.js` — service worker, кэширует приложение для работы без сети
- `manifest.json`, `icon-*.png` — чтобы устанавливалось на домашний экран

## Выпуск новой версии

Заменить `index.html` и **поднять `CACHE_VERSION` в `sw.js`** — иначе на уже установленных телефонах останется старая версия.
